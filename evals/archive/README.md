# Archived evals

`public-prompt-evals-2026-05.json` is the 12-case public prompt eval set (skill-creator
format) last updated 2026-05-19. No gate reads it: the maintained suites are
`skill-development/evals/evals.json` (development evals with fixture oracles) and
`evals/shared-benchmark.json` (shared harness manifest). Its fixture files moved with it
to `files/`, so the `evals/files/...` paths inside the JSON now resolve under
`evals/archive/files/`. Kept for history; do not cite it as current coverage.
