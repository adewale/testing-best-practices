**Base** `adewale/agentic-mermaid@f49196e7f5d6d2f0970a4a76fe62644ee5e9d004`. I found one current CI setup defect and three gaps in focused behavioral tests. ### Medium · The weekly coverage report is blocked by a missing CJK font

The November 23 scheduled run on the exact base failed on shard 1/3 at `src/__tests__/png-fonts.test.ts:89`. The public annotation names the missing font. The other two shards passed and the merge job skipped. The November 16 run failed on the same line in a different shard. The regular unit workflow installs WenQuanYi before running the tests. The weekly workflow installs JavaScript dependencies and builds the Node bundle, then runs the same unit collector without provisioning the font. Install the same fixture as the normal unit job at `.github/workflows/coverage.yml:32–36` and preserve the missing-resource guard. The test exercises the caller's ability to supply real glyphs. ### Medium · The PNG font test accepts the wrong face and missing glyphs

The Journey test checks for dark pixels to the **right** of the long label's box. It never checks that glyphs appear inside. The public font guide promises bundled Inter for ordinary Latin text, with DejaVu available as a fallback. The native adapter hands verified file paths to Resvg at `src/agent/png.ts:241`. The Journey box and the task text are separate marks. The test was introduced in `3c296024c12` specifically to detect font/measurement drift. [Test and native handoff](evidence/53-png-read.log) · [Font contract](evidence/82-font-reference-fixture.log) · [History](evidence/90-png-baseline-history.log)

I changed the native font list to **only DejaVu Sans**. All **20 cases** in the PNG-font, Journey SVG snapshot and PNG-determinism files passed. Both the healthy and fallback-only render had zero exterior ink columns. In the fallback-only render the default label's pixels changed to the healthy explicit-DejaVu label, even when the caller requested Inter. With **no bundled font files**, all 14 tests in the font file still passed. The task interior dropped from 504 dark columns to 13 near the center. A useful sibling did catch this broader fault because Flowcharts labeled A/B and X/Y became pixel-identical. [Fallback-only run](evidence/80-fallback-old.log) · [Broad fault and sibling failure](evidence/71-fontsuite-old-fault.log) · [Original image](evidence/journey-baseline.png) · [Fallback image](evidence/journey-dejavu-only.png) · [Missing-font image](evidence/journey-without-bundled-fonts.png)

**Repair the existing test at `src/__tests__/png-fonts.test.ts:55–75`.** Keep its overflow bound. Check for ink on both sides of the fixture's central decoration. For face selection, compare the actual task interior from the default, explicit Inter and explicit DejaVu renders. The default and explicit Inter crops agreed, the DejaVu crop differed, and changing the later fallback to `Inter, serif` preserved the Inter crop. The same comparison failed on the fallback-only adapter. This compares contract-derived relationships without committing a machine-specific PNG checksum. The positive ink assertion also failed under the no-font fault and passed after restoration. ### Medium · The two batch color-diagnostic tests send all format rows to SVG

Both tests encode `{ op, format, source }`. The public JSONL handler consumes `options.format` and defaults to SVG. The two fixtures therefore exercise SVG six times across Flowchart and Quadrant. The four terminal rows never select their intended route. With a valid color, the current form returned `data.svg` and an SVG receipt for every requested format. The nested form returned the corresponding SVG, ASCII and Unicode keys and receipts. The malformed-color response alone conceals this distinction. The two bad constructors were present when these cases were introduced in `1cde6faa800` and `5a9d37f3178`. [Returned formats](evidence/30-route-probe.log) · [Handler](evidence/19-batch-entry.log) · [Original commits](evidence/54-public-history-reports.log)

**Repair the two request constructors** at `src/__tests__/authored-style-color-admission.test.ts:203` and `src/__tests__/quadrant-style.test.ts:150`. I wrapped the terminal renderer's exception while retaining its cause, a change that converts this nominal CLI diagnostic from `INVALID_STYLE_COLOR` to `RENDER_FAILED`. The committed files passed **38/38**. Moving just the two `format` fields gave **36 pass, 2 fail** against that identical fault and **38/38** after restoring production. Keep the direct-renderer and hosted-SVG assertions. The successful-format property and theme-color tests exercise nearby behavior, including different diagnostic codes. The audit makes no whole-suite survival claim for the broad exception wrapper. ### Low · Structured local edits can rewrite mixed line endings without alarming the selected suites

The mutation policy promises that a local edit copies untouched lines byte for byte. The structured property varies comments, blank lines and indentation but joins every generated source with LF at `src/__tests__/property-source-preserving-edit.test.ts:45–51`. The fixed structured table separately compares untouched lines and upstream Mermaid readings. Existing homogeneous CRLF and opaque-body tests protect additional cases. The shared structured writer at `src/agent/source-projection.ts:1537–1547` handles the distinction between a retained line's terminator and an inserted line's default terminator. CLI, MCP and the editor expose this mode through the public editing surface. [Public contract](evidence/37-keep-contract.log) · [Generator](evidence/95-independent-oracles.log) · [Related CRLF cases](evidence/76-mixed-ending-overlap.log) · [Writer and entry point](evidence/87-join-classes.log)

**Repair one structured `set_label` case** alongside `src/__tests__/agent-source-preserving-edit.test.ts:646–665`. Give it mixed CRLF/LF input and compare the returned source with the literal one-label substitution. A one-line fault that used the file's inferred ending for every retained line changed unrelated bytes while reporting `method: local`. All **403 selected cases** passed with this fault under the repository's 30-second per-test setting. The byte probe caught it for mixed input and accepted ordinary LF and CRLF documents. On restored code all three inputs and the same 403 cases passed. This is a proposed shared-writer regression case, with the generated operations and independent upstream readings retained.
